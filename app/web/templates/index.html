How PhishLens works
  1. Parse the .eml file (sender, reply-to, body, images).
  2. Check headers: SPF, DKIM, DMARC, Reply-To mismatch.
  3. Extract every link, including links hidden in QR codes.
  4. VirusTotal checks each link's reputation (cached).
  5. AI reasoning (Groq) reads the evidence and explains it.
  6. Score all signals and return the verdict.
